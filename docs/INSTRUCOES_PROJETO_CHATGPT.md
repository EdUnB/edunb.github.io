## Como adicionar a conversa ao Projeto

1. Na barra lateral do ChatGPT, crie **Novo projeto**, nome `Site Acadêmico — Edgar A. Silveira`.
2. Neste chat existente, abra `•••` e selecione **Mover para projeto**, ou arraste o chat para o novo Projeto. Se essa opção não aparecer, crie um novo chat no Projeto e adicione este pacote como arquivo de referência.
3. Entre no Projeto e cole as instruções acima no campo de Instruções do projeto.
4. Adicione como fontes do Projeto, se desejar, o `README.md`, os documentos `docs/` e o ZIP do código. Para edição e distribuição, o repositório GitHub será a fonte principal de código.

O ChatGPT não executa a ação de criar ou mover Projetos automaticamente nesta conversa; é uma configuração de interface feita pelo usuário.
